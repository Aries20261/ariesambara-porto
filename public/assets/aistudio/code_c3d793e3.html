03

Mekanisme Pengisian Data: Manual vs Massal

Metode A: Input Manual (CMS & Quick Form)

Dirancang untuk penambahan dan kurasi data harian atau perbaikan deskripsi secara cepat:

✓ Form Input Visual: Menambah item pengalaman, portofolio baru, atau mengubah link kontak secara interaktif.
✓ Image Cropper & Optimizer: Menyesuaikan foto profil Aries Ambara dan aset gambar proyek secara otomatis ke format WebP terkompresi.
✓ Live Preview Toggle: Meninjau hasil tampilan di mockup mobile dan desktop sebelum diterbitkan.
Metode B: Input Massal (Bulk JSON / CSV Importer)

Disediakan untuk migrasi data riwayat karier dalam jumlah besar tanpa input berulang:

✓ JSON Schema Upload: Struktur standar untuk mengunggah seluruh riwayat pekerjaan, portfolio, dan skills sekaligus.
✓ CSV/Spreadsheet Importer: Aries dapat mengisi spreadsheet Excel/Google Sheets lalu mengunggahnya langsung.
✓ Data Validation Engine: Validasi otomatis format tanggal, status proyek, dan ketersediaan tautan eksternal.
Contoh Schema JSON untuk Import Massal portfolio_data_schema.json
